Sync my storage data

Sync my storage data is a utility that lets users connect their Google account and synchronize storage data that they explicitly authorize.

What the application does

The application uses Google OAuth to let a user securely authorize access to supported Google data without sharing the user's Google password with the application.

After authorization, the application uses only the Google data and permissions necessary to perform user-requested synchronization. Depending on the permissions granted on the Google consent screen, this may include basic Google account information and Google Drive file or folder data needed for synchronization.

Why Google data is requested

  • Account information: to identify the signed-in user and associate the authorized connection with that user.
  • Google Drive data: to locate, read, and synchronize files or folders that the user has authorized.
  • Write access, when requested: used only for synchronization actions initiated or configured by the user.

User control

Users decide whether to grant Google permissions and may revoke the application's access at any time through their Google Account permissions. The application does not sell Google user data or use it for advertising.

Privacy and terms

Details about how Google user data is accessed, used, stored, shared, and deleted are described in the Privacy Policy. Use of the application is also subject to the Terms of Service.
