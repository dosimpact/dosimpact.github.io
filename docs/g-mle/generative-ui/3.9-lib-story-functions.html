OpenUI Lang — 함수 사용 사례 59개

총 59개 항목 · 118개 예제를 설명한다. 각 항목은 한국어 설명, 위치 기반 호출 계약, 완성된 OpenUI Lang 프로그램을 포함한다.

이 문서의 범위와 읽는 방법​

이 문서는 OpenUI Lang을 사용해 UI를 기술하는 라이브러리의 독립적인 사용 설명서다. 특정 프로젝트의 저장소·소스 파일·로컬 서버·다른 문서를 열지 않아도 계약과 예제를 읽을 수 있도록 구성했다. 여기에 정의한 이름·인자 순서·동작은 이 문서가 설명하는 카탈로그의 계약이며, 모든 OpenUI 카탈로그에 동일한 항목이 기본 제공된다는 뜻은 아니다.

Markdown은 예제 코드를 보여주는 문서 형식이다. 코드를 실행해 실제 화면을 표시하려면 OpenUI Lang 파서·평가기·렌더러와 본문에 설명된 컴포넌트·함수·액션을 등록한 호스트 애플리케이션이 필요하다. 이 문서 자체가 실행 엔진이나 설치 패키지는 아니다.

공통 문법​

root = Col([Text("횟수: " + $count), Button("증가", @Set($count, $count + 1))])
$count = 0
  • root = ...: 화면 진입점이다. root에서 연결한 요소가 표시된다.
  • Col(...), Text(...): 등록된 컴포넌트를 생성하는 표현식이다.
  • $count = 0: 사용자가 변경할 수 있는 상태의 초깃값이다. 초깃값에는 숫자·문자열·배열·객체·null 같은 literal을 사용한다.
  • result = @Percent(3, 4): 계산 표현식이다. 해당 함수가 등록돼 있다면 75가 계산된다. 일반 변수 result와 상태 변수 $result는 구별한다.
  • @Set($count, 새값): 클릭 등의 이벤트에서 상태값을 바꾸는 내장 액션이다. 변경된 상태를 읽는 표현식과 UI가 다시 평가된다.
  • 조건 ? 참일때값 : 거짓일때값: 조건에 따라 값을 선택한다.
  • 인자는 위치 기반이다. ?가 붙은 계약 항목은 선택 인자이며 중간 인자를 건너뛸 때 예제처럼 null을 사용할 수 있다.
  • null, false, 0, ""은 서로 다른 값이다. 객체 키는 {"id": 1}처럼 따옴표로 감싼다.
  • 표현식은 참조를 정의보다 앞에 둘 수 있다. 따라서 첫 줄의 root가 뒤에 선언된 상태나 계산값을 참조하는 예제가 있다.

본문의 @Name(...)에는 값을 계산하는 함수와 이벤트를 실행하는 액션이 함께 등장한다. 함수는 결과값을 반환하고, 액션은 상태 변경·복사·대화 요청 같은 동작을 일으킨다. @Set·@Each 같은 내장 기능과 본문에서 설명하는 사용자 정의 항목은 구별한다.

계산과 상태 저장의 차이​

root = Col([Button("실행", @Set($result, @Pick(["A", "B", "C"]))), Text($result == null ? "null" : "결과: " + $result)])
$result = null

처음에는 null이 표시된다. 실행 버튼을 누르면 Pick이 하나를 뽑고 Set이 그 값을 상태에 저장한다. Text는 바뀐 상태를 표시한다. 다음 클릭 전까지 그 결과를 유지한다. 같은 값이 다시 뽑힐 수도 있다. Pick·Shuffle·Random·Now처럼 재평가 시 달라질 수 있는 값은 이런 방식으로 저장해 사용한다.

나머지 예제의 result = @함수(...)는 계산식을 선언하고 그 결과를 표시한다. 목록 수정 함수는 원본을 직접 변경하는 대신 새 목록을 반환한다. 목록 상태를 실제 갱신하려면 이벤트에서 @Set($items, @Append($items, "새 항목"))처럼 반환값을 저장한다.

입력 타입·인자 수가 맞지 않거나 함수 실행 중 오류가 생기면 런타임이 오류를 기록하고 null을 반환할 수 있다. null이 함수의 정상 결과인 경우도 있으므로 Find의 미일치·Change의 이전 값 0과 실행 실패를 구별한다. 로그의 표시 방식은 호스트마다 다르며 특별한 Console 로그가 기본 제공된다고 가정하지 않는다.

전체 목차​

  • Append — 목록 끝에 항목을 추가한 새 목록을 반환한다.

  • Prepend — 목록 앞에 항목을 추가한 새 목록을 반환한다.

  • Concat — 두 목록을 이어 붙인다.

  • Remove — 지정 필드 값이 일치하는 항목을 제거한다. 빈 필드명은 항목 자체를 비교한다.

  • RemoveAt — 지정 인덱스의 항목을 제거한다. 인덱스는 0부터 시작하며 음수는 뒤에서 센다.

  • Update — 조건 필드가 일치하는 객체의 지정 필드 값을 바꾼 새 목록을 반환한다.

  • Toggle — 항목이 없으면 추가하고 있으면 제거한다.

  • Includes — 목록에 항목이 있거나 문자열에 값이 포함되는지 확인한다.

  • Find — 필드 값이 일치하는 첫 항목을 반환한다. 없으면 null이다.

  • IndexOf — 목록에서 항목의 인덱스를 반환한다. 없으면 -1이다.

  • Take — 앞에서 N개를 가져온다. N이 음수면 뒤에서 가져온다.

  • Slice — 목록 또는 문자열을 시작 위치부터 끝 위치 직전까지 잘라낸다.

  • Unique — 중복을 제거하고 처음 등장한 순서를 유지한다.

  • Reverse — 순서를 뒤집은 새 목록을 반환한다.

  • Range — 시작값부터 끝값 직전까지 지정 간격의 숫자를 생성한다.

  • Pick — 목록에서 임의 항목을 고른다. 빈 목록은 null이다.

  • Shuffle — 목록을 무작위 순서로 섞은 사본을 반환한다.

  • Flatten — 목록 안의 목록을 한 단계 펼친다.

  • Chunk — 목록을 지정 크기의 작은 목록들로 나눈다.

  • Pow — 밑을 지수만큼 거듭제곱한다.

  • Sqrt — 제곱근을 계산한다. 음수 입력은 예외 처리 후 런타임에서 null이 된다.

  • Random — 범위 안의 난수를 생성한다. 정수 모드에서는 양 끝을 포함한다.

  • Clamp — 숫자를 최소·최대 범위 안으로 제한한다.

  • Percent — 부분 / 전체 × 100을 계산한다. 전체가 0이면 0이다.

  • Lerp — 두 값 사이를 비율 t로 선형 보간한다.

  • Allocate — 총액을 가중치 비율로 배분하고 반올림 후에도 합계가 맞도록 조정한다.

  • Payment — 원금·회차별 이율(퍼센트)·회차 수로 회차당 상환액을 계산한다.

  • Convert — 지원되는 길이·질량·부피·속도·면적·온도 단위를 변환한다.

  • Format — 숫자를 일반·통화·퍼센트·축약 형식의 문자열로 표시한다.

  • Join — 목록 항목 또는 지정 필드를 구분자로 연결한다.

  • Plural — 수량과 영어 단어의 단수·복수를 표시한다.

  • Pad — 문자열 앞부분을 지정한 문자로 채워 길이를 맞춘다.

  • Upper — 문자열을 대문자로 바꾼다.

  • Lower — 문자열을 소문자로 바꾼다.

  • Trim — 앞뒤 공백을 제거한다.

  • Capitalize — 각 단어의 첫 글자를 대문자로 바꾼다.

  • Split — 구분자로 문자열을 나누고 각 항목의 공백과 빈 항목을 제거한다.

  • Replace — 일치하는 모든 문자열을 교체한다.

  • Duration — 초를 짧은 시간 표현 또는 시계 형식으로 바꾼다.

  • Default — 값이 null·빈 문자열·NaN 등일 때 대체값을 사용한다. 숫자 0은 유지한다.

  • MixColor — 두 hex 색상을 비율 t로 혼합한다.

  • Now — 현재 시각을 ISO 문자열로 반환한다.

  • Today — 브라우저 시간대의 오늘 날짜를 YYYY-MM-DD로 반환한다.

  • FormatDate — 날짜를 지정한 표시 형식으로 바꾼다.

  • AddDays — 날짜에 일수를 더하거나 뺀다.

  • AddMonths — 개월 수를 더한다. 원래 날짜의 일이 새로 계산된 달에 없으면 해당 달의 마지막 날로 맞춘다.

  • DaysBetween — 두 날짜 사이의 달력상 일수 차이를 계산한다.

  • MonthsBetween — 두 날짜 사이의 온전한 개월 수를 계산한다.

  • StartOf — 날짜가 속한 주(월요일)·월·년의 시작일을 반환한다.

  • GroupBy — 키별로 묶어 합계·평균·개수 등의 집계를 반환한다.

  • Pivot — 행 키·열 키별로 데이터를 교차 집계한다.

  • Top — 필드 기준으로 가장 큰 값 또는 작은 값의 상위 N개 행을 반환한다.

  • Between — 필드가 최소·최대 범위에 있는 행을 선택한다. 양 끝을 포함하며, 경계값이 null이면 해당 방향으로는 범위를 제한하지 않는다.

  • Bucket — 날짜를 일·주·월로 묶어 집계한다. 합계·개수의 빈 기간은 0으로 채운다.

  • Cumulative — 필드 값을 순서대로 누적 합계로 바꾼 사본을 반환한다.

  • MovingAvg — 최근 window개 값의 평균으로 필드를 바꾼다.

  • Change — 이전 값 대비 현재 값의 증감률을 계산한다. 이전 값이 0이면 null이다.

  • Histogram — 숫자를 같은 폭의 구간으로 나누고 구간별 개수를 반환한다.

  • Stats — 개수·최소·최대·평균·중앙값·표준편차를 반환한다. 빈 목록의 통계값은 모두 0이다.

Append​

목록 끝에 항목을 추가한 새 목록을 반환한다.

호출 계약

Append(list: any[], item: any) → any[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: [1, 2, 3]. 예제 2: ["첫 항목"].

예제 1. 기본 호출​

root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Append([1,2], 3)

예제 2. 다른 입력 / 경계 사례​

root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Append([], "첫 항목")

Prepend​

목록 앞에 항목을 추가한 새 목록을 반환한다.

호출 계약

Prepend(list: any[], item: any) → any[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: [1, 2, 3]. 예제 2: ["첫 항목"].

예제 1. 기본 호출​

root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Prepend([2,3], 1)

예제 2. 다른 입력 / 경계 사례​

root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Prepend([], "첫 항목")

Concat​

두 목록을 이어 붙인다.

호출 계약

Concat(list: any[], more: any[]) → any[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: [1, 2, 3, 4]. 예제 2: [1].

예제 1. 기본 호출​

root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Concat([1,2], [3,4])

예제 2. 다른 입력 / 경계 사례​

root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Concat([], [1])

Remove​

지정 필드 값이 일치하는 항목을 제거한다. 빈 필드명은 항목 자체를 비교한다.

호출 계약

Remove(list: any[], field: string, value: any) → any[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: id=1만 남는다. 예제 2: ["배"].

예제 1. 기본 호출​

root = Col([Table(["id"], @Each(result, "r", [r.id]))])
result = @Remove([{"id":1},{"id":2}], "id", 2)

예제 2. 다른 입력 / 경계 사례​

root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Remove(["사과","배"], "", "사과")

RemoveAt​

지정 인덱스의 항목을 제거한다. 인덱스는 0부터 시작하며 음수는 뒤에서 센다.

호출 계약

RemoveAt(list: any[], index: number) → any[]

Pivot(rows: any[], rowKey: string, colKey: string, field?: string, agg?: "sum" | "avg" | "count" | "min" | "max") → Record<string, string | number>[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: East 행에 A=10, B=20. 예제 2: West 행에 A=30.

예제 1. 기본 호출​

root = Col([Table(["region", "A", "B"], @Each(result, "r", [r.region, r.A, r.B]))])
result = @Pivot([{"region":"East","product":"A","value":10},{"region":"East","product":"B","value":20}], "region", "product", "value", "sum")

예제 2. 다른 입력 / 경계 사례​

root = Col([Table(["region", "A"], @Each(result, "r", [r.region, r.A]))])
result = @Pivot([{"region":"West","product":"A","value":30}], "region", "product", "value", "sum")

Top​

필드 기준으로 가장 큰 값 또는 작은 값의 상위 N개 행을 반환한다.

호출 계약

Top(rows: any[], field: string, n: number, direction?: "desc" | "asc") → any[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: value 30, 20 순서. 예제 2: value 10인 행.

예제 1. 기본 호출​

root = Col([Table(["value"], @Each(result, "r", [r.value]))])
result = @Top([{"value":10},{"value":30},{"value":20}], "value", 2, "desc")

예제 2. 다른 입력 / 경계 사례​

root = Col([Table(["value"], @Each(result, "r", [r.value]))])
result = @Top([{"value":10},{"value":30},{"value":20}], "value", 1, "asc")

Between​

필드가 최소·최대 범위에 있는 행을 선택한다. 양 끝을 포함하며, 경계값이 null이면 해당 방향으로는 범위를 제한하지 않는다.

호출 계약

Between(rows: any[], field: string, min?: any, max?: any) → any[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: value 20인 행. 예제 2: value 10, 20인 행.

예제 1. 기본 호출​

root = Col([Table(["value"], @Each(result, "r", [r.value]))])
result = @Between([{"value":10},{"value":20},{"value":30}], "value", 15, 25)

예제 2. 다른 입력 / 경계 사례​

root = Col([Table(["value"], @Each(result, "r", [r.value]))])
result = @Between([{"value":10},{"value":20},{"value":30}], "value", null, 20)

Bucket​

날짜를 일·주·월로 묶어 집계한다. 합계·개수의 빈 기간은 0으로 채운다.

호출 계약

Bucket(rows: any[], dateField: string, unit: "day" | "week" | "month", field?: string, agg?: "sum" | "avg" | "count" | "min" | "max") → {key: string | number, value: number}[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: 10월 1일 10, 2일 0, 3일 30. 예제 2: 2026-10 합계 10, 2026-11 합계 30.

예제 1. 기본 호출​

root = Col([Table(["key", "value"], @Each(result, "r", [r.key, r.value]))])
result = @Bucket([{"date":"2026-10-01","value":10},{"date":"2026-10-03","value":30}], "date", "day", "value", "sum")

예제 2. 다른 입력 / 경계 사례​

root = Col([Table(["key", "value"], @Each(result, "r", [r.key, r.value]))])
result = @Bucket([{"date":"2026-10-01","value":10},{"date":"2026-11-01","value":30}], "date", "month", "value", "sum")

Cumulative​

필드 값을 순서대로 누적 합계로 바꾼 사본을 반환한다.

호출 계약

Cumulative(rows: any[], field: string) → any[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: [10,30,60]. 예제 2: value 10, 30인 두 행.

예제 1. 기본 호출​

root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Cumulative([10,20,30], "")

예제 2. 다른 입력 / 경계 사례​

root = Col([Table(["value"], @Each(result, "r", [r.value]))])
result = @Cumulative([{"value":10},{"value":20}], "value")

최근 window개 값의 평균으로 필드를 바꾼다.

호출 계약

MovingAvg(rows: any[], field: string, window: number) → any[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: [10,15,25,35]. 예제 2: [10,15,20]. 초기 구간은 존재하는 값만 평균 낸다.

root = Col([Table(["결과"], @Each(result, "r", [r]))])

Change​

이전 값 대비 현재 값의 증감률을 계산한다. 이전 값이 0이면 null이다.

호출 계약

Change(current: number, previous: number) → number

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: 20. 예제 2: 이전 값이 0이므로 null.

예제 1. 기본 호출​

root = Col([Text(result == null ? "null" : "결과: " + result)])
result = @Change(120, 100)

예제 2. 다른 입력 / 경계 사례​

root = Col([Text(result == null ? "null" : "결과: " + result)])
result = @Change(120, 0)

Histogram(values: number[], bins: number, min?: number, max?: number) → {key: string, value: number, start: number, end: number}[]

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

root = Col([Table(["key", "value"], @Each(result, "r", [r.key, r.value]))])

Stats​

개수·최소·최대·평균·중앙값·표준편차를 반환한다. 빈 목록의 통계값은 모두 0이다.

호출 계약

Stats(values: number[]) → {count: number, min: number, max: number, mean: number, median: number, stdev: number}

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.

기대 결과

예제 1: count=4, min=10, max=40, mean=25, median=25, stdev 약 11.18. 예제 2: 모든 통계값 0.

예제 1. 기본 호출​

root = Col([Table(["count", "min", "max", "mean", "median", "stdev"], [[result.count, result.min, result.max, result.mean, result.median, result.stdev]])])
result = @Stats([10,20,30,40])

예제 2. 다른 입력 / 경계 사례​

root = Col([Table(["count", "min", "max", "mean", "median", "stdev"], [[result.count, result.min, result.max, result.mean, result.median, result.stdev]])])
result = @Stats([])

확인할 사항​

  • 계약의 인자 순서와 타입을 확인한다. 숫자와 숫자 문자열은 같지 않다.

  • 기대 결과와 다른 경우 해당 함수나 컴포넌트의 계약, 상태 연결, 호스트의 오류 처리를 확인한다.
  • 예제는 학습용이다. 모든 호스트에서 자동 실행되거나 동일한 카탈로그가 설치돼 있다는 의미는 아니다.
