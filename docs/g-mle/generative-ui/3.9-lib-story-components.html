OpenUI Lang — 컴포넌트 사용 사례 55개

총 55개 항목 · 111개 예제를 설명한다. 각 항목은 한국어 설명, 위치 기반 호출 계약, 완성된 OpenUI Lang 프로그램을 포함한다.

이 문서의 범위와 읽는 방법​

이 문서는 OpenUI Lang을 사용해 UI를 기술하는 라이브러리의 독립적인 사용 설명서다. 특정 프로젝트의 저장소·소스 파일·로컬 서버·다른 문서를 열지 않아도 계약과 예제를 읽을 수 있도록 구성했다. 여기에 정의한 이름·인자 순서·동작은 이 문서가 설명하는 카탈로그의 계약이며, 모든 OpenUI 카탈로그에 동일한 항목이 기본 제공된다는 뜻은 아니다.

Markdown은 예제 코드를 보여주는 문서 형식이다. 코드를 실행해 실제 화면을 표시하려면 OpenUI Lang 파서·평가기·렌더러와 본문에 설명된 컴포넌트·함수·액션을 등록한 호스트 애플리케이션이 필요하다. 이 문서 자체가 실행 엔진이나 설치 패키지는 아니다.

공통 문법​

root = Col([Text("횟수: " + $count), Button("증가", @Set($count, $count + 1))])
$count = 0
  • root = ...: 화면 진입점이다. root에서 연결한 요소가 표시된다.
  • Col(...), Text(...): 등록된 컴포넌트를 생성하는 표현식이다.
  • $count = 0: 사용자가 변경할 수 있는 상태의 초깃값이다. 초깃값에는 숫자·문자열·배열·객체·null 같은 literal을 사용한다.
  • result = @Percent(3, 4): 계산 표현식이다. 해당 함수가 등록돼 있다면 75가 계산된다. 일반 변수 result와 상태 변수 $result는 구별한다.
  • @Set($count, 새값): 클릭 등의 이벤트에서 상태값을 바꾸는 내장 액션이다. 변경된 상태를 읽는 표현식과 UI가 다시 평가된다.
  • 조건 ? 참일때값 : 거짓일때값: 조건에 따라 값을 선택한다.
  • 인자는 위치 기반이다. ?가 붙은 계약 항목은 선택 인자이며 중간 인자를 건너뛸 때 예제처럼 null을 사용할 수 있다.
  • null, false, 0, ""은 서로 다른 값이다. 객체 키는 {"id": 1}처럼 따옴표로 감싼다.
  • 표현식은 참조를 정의보다 앞에 둘 수 있다. 따라서 첫 줄의 root가 뒤에 선언된 상태나 계산값을 참조하는 예제가 있다.

본문의 @Name(...)에는 값을 계산하는 함수와 이벤트를 실행하는 액션이 함께 등장한다. 함수는 결과값을 반환하고, 액션은 상태 변경·복사·대화 요청 같은 동작을 일으킨다. @Set·@Each 같은 내장 기능과 본문에서 설명하는 사용자 정의 항목은 구별한다.

화면을 읽는 기준​

레이아웃 항목은 배치·간격·정렬, 입력 항목은 상태 변화, 미디어 항목은 외부 콘텐츠 표시, SVG 항목은 좌표와 도형의 변화를 관찰한다. MapMarker는 Map 안에서, SVG 도형은 Svg 안에서 사용한다. 컴포넌트 이름이 TypeScript 변수 이름과 같아야 하는 것은 아니며, 여기서는 계약에 나온 DSL 이름만 사용한다.

Form 안의 @ToAssistant("요청")는 폼 값과 후속 요청을 호스트에 전달하는 내장 액션이다. 실제 AI 대화로 이어질지는 호스트가 결정한다. Link는 HTTP(S) 주소를 연다. 이미지·지도·YouTube는 네트워크와 외부 서비스가 필요하며 문서에 포함된 정적 파일이 아니다. Image 예제의 HTTPS 주소도 외부 예시 이미지다. HtmlView는 별도 샌드박스 안에서 HTML을 실행한다.

전체 목차​

  • Col — 자식 요소를 세로로 배치한다. gap을 생략하면 문서 흐름에 맞춘 기본 간격을 적용한다.

  • Row — 자식 요소를 가로로 배치하고 간격·정렬·줄바꿈을 지정한다.

  • Box — 방향·여백·배경·테두리·크기를 지정하는 범용 컨테이너다.

  • Grid — 자식 요소를 같은 너비의 열에 배치한다. 최소 자식 너비로 반응형 열 수를 조절한다.

  • Card — 관련 콘텐츠를 테두리 또는 부드러운 배경의 패널로 묶는다.

  • Carousel — 카드나 콘텐츠를 가로로 스크롤하고 항목 단위로 이동한다.

  • Popover — 트리거를 눌렀을 때 추가 설명을 작은 패널로 표시한다.

  • Divider — 콘텐츠 사이에 구분선을 표시한다.

  • Spacer — Row 안의 남은 공간을 채워 요소 사이를 벌린다.

  • Title — 제목이나 강조 숫자를 크기·색상과 함께 표시한다.

  • Text — 일반 문장과 인라인 Markdown 서식을 표시한다.

  • Caption — 작은 보조 설명을 표시한다.

  • Label — 필드나 그룹의 이름을 표시한다.

  • Badge — 상태나 짧은 사실을 색상·아이콘이 있는 태그로 표시한다.

  • Link — HTTP(S) 링크를 새 탭에서 연다.

  • List — 문자열 또는 ListItem을 글머리표·번호·타임라인으로 표시한다.

  • ListItem — 제목·설명·사용자 지정 마커를 갖는 목록 항목이다.

  • Markdown — 제목·목록·인용·코드·표가 있는 Markdown 본문을 표시한다.

  • Quote — 인용 문장과 선택적 출처를 표시한다.

  • Code — 복사 버튼이 있는 코드 블록을 표시한다.

  • Math — LaTeX 수식을 블록 또는 인라인으로 표시한다.

  • Button — 클릭 액션을 실행하는 버튼이다. 스타일·크기·아이콘·비활성 상태를 지정할 수 있다.

  • IconButton — 접근성 라벨을 갖는 아이콘 버튼이다.

  • Pressable — 임의의 콘텐츠를 클릭 가능한 선택 타일로 만든다.

  • Input — 문자열 또는 숫자를 상태 변수에 바인딩하는 입력 컴포넌트다.

  • TextArea — 여러 줄 문자열을 입력한다.

  • Select — 긴 선택 목록에 적합한 드롭다운이다.

  • SegmentedControl — 소수의 선택지를 나란히 배치한다.

  • Slider — 최솟값·최댓값·간격을 지정해 숫자 상태를 조절한다.

  • Checkbox — 불리언 상태를 변경하고 완료 시 취소선을 표시할 수 있다.

  • RadioGroup — 하나의 항목을 목록·알약·카드 형태로 선택한다.

  • DatePicker — YYYY-MM-DD 날짜 상태를 입력한다.

  • Timer — 시작·일시 정지·초기화를 지원하는 카운트다운이다.

  • Form — 입력을 묶고 ToAssistant로 제출할 때 폼 값을 함께 전달한다.

  • SearchImage — 검색어로 사진을 찾는다. 외부 이미지 서비스의 응답에 의존한다.

  • Image — 지정 URL의 이미지를 표시하고 실패 시 대체 검색을 시도한다.

  • Icon — Lucide 이름으로 아이콘을 표시한다.

  • Table — 열 이름과 행별 셀 배열로 표를 표시한다.

  • Chart — 행 데이터로 막대·선·영역·원형·도넛·산점도 차트를 표시한다.

  • Map — 마커에 맞춘 지도를 표시하고 경로·선택 상태를 연결할 수 있다.

  • MapMarker — Map 안에서 이름·좌표·분류·아이콘을 갖는 장소를 정의한다.

  • YouTube — 영상 ID 또는 URL로 YouTube를 임베드한다.

  • Flashcard — 클릭하면 앞뒷면이 전환되는 학습 카드다.

  • Celebration — 조건이 true가 될 때 축하 효과를 표시한다.

  • Svg — 도형을 배치할 좌표계와 SVG 캔버스를 정의한다.

  • Circle — 중심 좌표와 반지름으로 원을 그린다.

  • Ellipse — 중심 좌표와 두 반지름으로 타원을 그린다.

  • Rect — 위치·크기·모서리 반경으로 사각형을 그린다.

  • Line — 두 좌표 사이에 선을 그린다.

  • Path — SVG 경로 문자열로 곡선과 도형을 그린다.

  • Polyline — 여러 좌표를 연결하는 꺾은선을 그린다.

  • Polygon — 여러 좌표를 닫힌 다각형으로 연결한다.

  • G — 도형을 그룹으로 묶어 이동·회전·투명도를 함께 적용한다.

  • SvgText — SVG 좌표에 정렬·크기·색상을 지정한 글자를 표시한다.

  • HtmlView — 샌드박스 iframe 안에서 HTML과 인라인 JavaScript를 실행한다.

Col​

자식 요소를 세로로 배치한다. gap을 생략하면 문서 흐름에 맞춘 기본 간격을 적용한다.

호출 계약

Col(children: Node[], gap?: number, align?: "start" | "center" | "end" | "stretch")

이 항목의 예제는 Col 컴포넌트만 사용한다. 문자열을 각각 Col로 감싸 실제 요소 사이의 간격·정렬 차이를 보여준다.

예제 1. 기본 세로 흐름​

root = Col([Col(["첫 번째 항목"]), Col(["두 번째 항목"]), Col(["세 번째 항목"])])

예제 2. 간격 4 = 16px​

root = Col([Col(["첫 번째 항목"]), Col(["두 번째 항목"]), Col(["세 번째 항목"])], 4)

예제 3. 중첩과 정렬​

root = Col([Col([Col(["안쪽 A"]), Col(["안쪽 B"])], 2), Col([Col(["안쪽 C"]), Col(["안쪽 D"])], 4)], 6, "center")

Row​

자식 요소를 가로로 배치하고 간격·정렬·줄바꿈을 지정한다.

호출 계약

Row(children: Node[], gap?: number, align?: "start" | "center" | "end" | "stretch", justify?: "start" | "center" | "end" | "between", wrap?: boolean)

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.

예제 1. 기본 가로 배치​

root = Col([Row([Text("왼쪽"), Text("가운데"), Text("오른쪽")], 4)])

예제 2. 양끝 정렬​

root = Col([Row([Text("시작"), Text("끝")], 2, "center", "between", true)])

Box​

방향·여백·배경·테두리·크기를 지정하는 범용 컨테이너다.

호출 계약

Box(children?: Node[], direction?: "row" | "col", gap?: number, padding?: number, background?: Color, radius?: Radius, border?: boolean, width?: Length, height?: Length, flex?: number, align?: "start" | "center" | "end" | "stretch", justify?: "start" | "center" | "end" | "between", wrap?: boolean)

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.

예제 1. 배경·테두리​

root = Col([Box([Text("배경과 여백")], "col", 2, 4, "surface", "lg", true)])

예제 2. 가로 컨테이너​

root = Col([Box([Text("가로 A"), Text("가로 B")], "row", 4, 6, "info", "xl")])

Grid​

자식 요소를 같은 너비의 열에 배치한다. 최소 자식 너비로 반응형 열 수를 조절한다.

호출 계약

Grid(children: Node[], columns?: number, minChildWidth?: number, gap?: number)

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.

예제 1. 2열 그리드​

root = Col([Grid([Card(["A"]), Card(["B"]), Card(["C"]), Card(["D"])], 2, 120, 4)])

예제 2. 반응형 최소 너비​

root = Col([Grid([Card(["A"]), Card(["B"]), Card(["C"])], 3, 160, 2)])

Card​

관련 콘텐츠를 테두리 또는 부드러운 배경의 패널로 묶는다.

호출 계약

Card(children: Node[], variant?: "outline" | "soft", padding?: number, gap?: number)

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.

예제 1. 테두리 카드​

root = Col([Card([Text("기본 테두리 카드")])])

예제 2. 배경과 내부 간격​

root = Col([Card([Text("부드러운 배경"), Text("여백 6")], "soft", 6, 3)])

Carousel​

카드나 콘텐츠를 가로로 스크롤하고 항목 단위로 이동한다.

호출 계약

Carousel(children: Node[], itemWidth?: number, gap?: number)

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.

확인할 사항​

  • 계약의 인자 순서와 타입을 확인한다. 숫자와 숫자 문자열은 같지 않다.
  • 코드를 읽을 때 초기 상태, 이벤트 발생, 계산 결과, 화면 갱신을 순서대로 따라간다.
  • 기대 결과와 다른 경우 해당 함수나 컴포넌트의 계약, 상태 연결, 호스트의 오류 처리를 확인한다.
  • 예제는 학습용이다. 모든 호스트에서 자동 실행되거나 동일한 카탈로그가 설치돼 있다는 의미는 아니다.
