# OpenUI Lang — 함수 사용 사례 59개

총 **59개 항목 · 118개 예제**를 설명한다. 각 항목은 한국어 설명, 위치 기반 호출 계약, 완성된 OpenUI Lang 프로그램을 포함한다.

## 이 문서의 범위와 읽는 방법

이 문서는 OpenUI Lang을 사용해 UI를 기술하는 라이브러리의 독립적인 사용 설명서다. 특정 프로젝트의 저장소·소스 파일·로컬 서버·다른 문서를 열지 않아도 계약과 예제를 읽을 수 있도록 구성했다. 여기에 정의한 이름·인자 순서·동작은 이 문서가 설명하는 카탈로그의 계약이며, 모든 OpenUI 카탈로그에 동일한 항목이 기본 제공된다는 뜻은 아니다.

Markdown은 예제 코드를 보여주는 문서 형식이다. 코드를 실제 화면으로 실행하려면 OpenUI Lang 파서·평가기·렌더러와 본문에 설명된 컴포넌트·함수·액션을 등록한 호스트 애플리케이션이 필요하다. 이 문서 자체가 실행 엔진이나 설치 패키지는 아니다.

### 공통 문법

```openui-lang
root = Col([Text("횟수: " + $count), Button("증가", @Set($count, $count + 1))])
$count = 0
```

- `root = ...`: 화면 진입점이다. root에서 연결한 요소가 표시된다.
- `Col(...)`, `Text(...)`: 등록된 컴포넌트를 생성하는 표현식이다.
- `$count = 0`: 사용자가 변경할 수 있는 상태의 초기값이다. 초기값에는 숫자·문자열·배열·객체·null 같은 literal을 사용한다.
- `result = @Percent(3, 4)`: 계산 표현식이다. 해당 함수가 등록돼 있다면 75가 계산된다. 일반 변수 `result`와 상태 변수 `$result`는 구별한다.
- `@Set($count, 새값)`: 클릭 등의 이벤트에서 상태 값을 바꾸는 내장 액션이다. 변경된 상태를 읽는 표현식과 UI가 다시 평가된다.
- `조건 ? 참일때값 : 거짓일때값`: 조건에 따라 값을 선택한다.
- 인자는 위치 기반이다. `?`가 붙은 계약 항목은 선택 인자이며 중간 인자를 건너뛸 때 예제처럼 `null`을 사용할 수 있다.
- `null`, `false`, `0`, `""`은 서로 다른 값이다. 객체 키는 `{"id": 1}`처럼 따옴표로 감싼다.
- 표현식은 참조를 정의보다 앞에 둘 수 있다. 따라서 첫 줄의 root가 뒤에 선언된 상태나 계산값을 참조하는 예제가 있다.

본문의 `@Name(...)`에는 값을 계산하는 함수와 이벤트를 실행하는 액션이 함께 등장한다. 함수는 결과값을 반환하고, 액션은 상태 변경·복사·대화 요청 같은 동작을 일으킨다. `@Set`·`@Each` 같은 내장 기능과 본문에서 설명하는 사용자 정의 항목은 구별한다.

### 계산과 상태 저장의 차이

```openui-lang
root = Col([Button("실행", @Set($result, @Pick(["A", "B", "C"]))), Text($result == null ? "null" : "결과: " + $result)])
$result = null
```

처음에는 null이 표시된다. 실행 버튼을 누르면 Pick이 하나를 뽑고 Set이 그 값을 상태에 저장한다. Text는 바뀐 상태를 표시한다. 다음 클릭 전까지 그 결과를 유지한다. 같은 값이 다시 뽑힐 수도 있다. Pick·Shuffle·Random·Now처럼 재평가 시 달라질 수 있는 값은 이런 방식으로 저장해 사용한다.

나머지 예제의 `result = @함수(...)`는 계산식을 선언하고 그 결과를 표시한다. 목록 수정 함수는 원본을 직접 변경하는 대신 새 목록을 반환한다. 목록 상태를 실제 갱신하려면 이벤트에서 `@Set($items, @Append($items, "새 항목"))`처럼 반환값을 저장한다.

입력 타입·인자 수가 맞지 않거나 함수 실행 중 오류가 생기면 런타임이 오류를 기록하고 null을 반환할 수 있다. null이 함수의 정상 결과인 경우도 있으므로 Find의 미일치·Change의 이전 값 0과 실행 실패를 구별한다. 로그의 표시 방식은 호스트마다 다르며 특별한 Console 로그가 기본 제공된다고 가정하지 않는다.

## Append

목록 끝에 항목을 추가한 새 목록을 반환한다.


**호출 계약**

```text
Append(list: any[], item: any) → any[]
```

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.


**기대 결과**

예제 1: `[1, 2, 3]`. 예제 2: `["첫 항목"]`.

### 예제 1. 기본 호출

```openui-lang
root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Append([1,2], 3)
```


### 예제 2. 다른 입력 / 경계 사례

```openui-lang
root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Append([], "첫 항목")
```

## Remove

지정 필드 값이 일치하는 항목을 제거한다. 빈 필드명은 항목 자체를 비교한다.


**호출 계약**

```text
Remove(list: any[], field: string, value: any) → any[]
```

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.


**기대 결과**

예제 1: id=1만 남는다. 예제 2: `["배"]`.

### 예제 1. 기본 호출

```openui-lang
root = Col([Table(["id"], @Each(result, "r", [r.id]))])
result = @Remove([{"id":1},{"id":2}], "id", 2)
```


### 예제 2. 다른 입력 / 경계 사례

```openui-lang
root = Col([Table(["결과"], @Each(result, "r", [r]))])
result = @Remove(["사과","배"], "", "사과")
```


## RemoveAt

지정 인덱스의 항목을 제거한다. 인덱스는 0부터 시작하며 음수는 뒤에서 센다.


**호출 계약**

```text
RemoveAt(list: any[], index: number) → any[]
```

호출 인자를 바꾸면 결과가 어떻게 달라지는지 비교한다. 예제의 root는 계산 결과를 Text 또는 Table로 표시한다.


**기대 결과**

예제 1: `["A", "C"]`. 예제 2: `["A", "B"]`.

## 확인할 사항

- 계약의 인자 순서와 타입을 확인한다. 숫자와 숫자 문자열은 같지 않다.
