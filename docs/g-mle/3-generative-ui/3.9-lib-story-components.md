# OpenUI Lang — 컴포넌트 사용 사례 55개

총 **55개 항목 · 111개 예제**를 설명한다. 각 항목은 한국어 설명, 위치 기반 호출 계약, 완성된 OpenUI Lang 프로그램을 포함한다.

## 이 문서의 범위와 읽는 방법

이 문서는 OpenUI Lang을 사용해 UI를 기술하는 라이브러리의 독립적인 사용 설명서다. 특정 프로젝트의 저장소·소스 파일·로컬 서버·다른 문서를 열지 않아도 계약과 예제를 읽을 수 있도록 구성했다. 여기에 정의한 이름·인자 순서·동작은 이 문서가 설명하는 카탈로그의 계약이며, 모든 OpenUI 카탈로그에 동일한 항목이 기본 제공된다는 뜻은 아니다.

Markdown은 예제 코드를 보여주는 문서 형식이다. 코드를 실제 화면으로 실행하려면 OpenUI Lang 파서·평가기·렌더러와 본문에 설명된 컴포넌트·함수·액션을 등록한 호스트 애플리케이션이 필요하다. 이 문서 자체가 실행 엔진이나 설치 패키지는 아니다.

### 공통 문법

```openui-lang
root = Col([Text("횟수: " + $count), Button("증가", @Set($count, $count + 1))])
$count = 0
```

- `root = ...`: 화면 진입점이다. root에서 연결한 요소가 표시된다.
- `Col(...)`, `Text(...)`: 등록된 컴포넌트를 생성하는 표현식이다.
- `$count = 0`: 사용자가 변경할 수 있는 상태의 초기값이다. 초기값에는 숫자·문자열·배열·객체·null 같은 literal을 사용한다.
- `result = @Percent(3, 4)`: 계산 표현식이다. 해당 함수가 등록돼 있다면 75가 계산된다. 일반 변수 `result`와 상태 변수 `$result`는 구별한다.
- `@Set($count, 새값)`: 클릭 등의 이벤트에서 상태 값을 바꾸는 내장 액션이다. 변경된 상태를 읽는 표현식과 UI가 다시 평가된다.
- `조건 ? 참일때값 : 거짓일때값`: 조건에 따라 값을 선택한다.
- 인자는 위치 기반이다. `?`가 붙은 계약 항목은 선택 인자이며 중간 인자를 건너뛸 때 예제처럼 `null`을 사용할 수 있다.
- `null`, `false`, `0`, `""`은 서로 다른 값이다. 객체 키는 `{"id": 1}`처럼 따옴표로 감싼다.
- 표현식은 참조를 정의보다 앞에 둘 수 있다. 따라서 첫 줄의 root가 뒤에 선언된 상태나 계산값을 참조하는 예제가 있다.

### 예제에 사용하는 보조 요소와 타입

| 이름 | 의미 / 최소 사용 계약 |
| --- | --- |
| `Col(children, gap?, align?)` | 자식을 세로로 배치한다. gap 숫자는 4px 단위이며, 예를 들어 4는 16px이다. |
| `Text(text, size?, color?)` | 문장이나 문자열로 변환한 결과를 표시한다. |
| `Table(columns, rows)` | 열 이름 배열과 행별 셀 배열로 표를 표시한다. |
| `Button(label, action?)` | 클릭하면 action을 실행한다. |
| `Input($value, label?, type?)` | 문자열·숫자 입력을 상태 변수에 연결한다. type은 text 또는 number다. |
| `Box(children?, direction?, gap?, padding?, background?)` | 콘텐츠를 감싸 방향·간격·배경 등을 지정한다. |
| `@Each(list, "item", expression)` | 목록 각 항목에 expression을 적용해 결과 목록을 만든다. |
| `@Join(list, separator?, field?)` | 항목 또는 지정 필드를 문자열로 연결한다. |
| `@Set($state, value)` | 이벤트 발생 시 상태를 value로 바꾼다. |
| `Node` / `Node[]` | 렌더링할 문자열·컴포넌트 표현식 / 그 목록이다. |
| `$binding<T>` | T 타입 값을 읽고 변경할 수 있는 상태 연결이다. 호출에서는 `$value`를 전달한다. |
| `ActionExpression` | 클릭·제출 등의 이벤트에서 실행할 액션 표현식이다. |
| `Color` | ink·muted·surface·info·success·warning·danger 등의 토큰 또는 CSS 색상이다. |
| `Radius` | sm·md·lg·xl·full 또는 숫자로 지정한 모서리 반경이다. |
| `Length` | 픽셀 숫자 또는 `"50%"` 같은 CSS 길이다. |
| `Record<string, T>` | 문자열 키마다 T 타입 값을 갖는 객체다. |

본문의 `@Name(...)`에는 값을 계산하는 함수와 이벤트를 실행하는 액션이 함께 등장한다. 함수는 결과값을 반환하고, 액션은 상태 변경·복사·대화 요청 같은 동작을 일으킨다. `@Set`·`@Each` 같은 내장 기능과 본문에서 설명하는 사용자 정의 항목은 구별한다.

### 화면을 읽는 기준

레이아웃 항목은 배치·간격·정렬, 입력 항목은 상태 변화, 미디어 항목은 외부 콘텐츠 표시, SVG 항목은 좌표와 도형의 변화를 관찰한다. `MapMarker`는 `Map` 안에서, SVG 도형은 `Svg` 안에서 사용한다. 컴포넌트 이름이 TypeScript 변수 이름과 같아야 하는 것은 아니며, 여기서는 계약에 나온 DSL 이름만 사용한다.

`Form` 안의 `@ToAssistant("요청")`는 폼 값과 후속 요청을 호스트에 전달하는 내장 액션이다. 실제 AI 대화로 이어질지는 호스트가 결정한다. `Link`는 HTTP(S) 주소를 연다. 이미지·지도·YouTube는 네트워크와 외부 서비스가 필요하며 문서에 포함된 정적 파일이 아니다. Image 예제의 HTTPS 주소도 외부 예시 이미지다. HtmlView는 별도 샌드박스 안에서 HTML을 실행한다.

## Col

자식 요소를 세로로 배치한다. gap을 생략하면 문서 흐름에 맞춘 기본 간격을 적용한다.


**호출 계약**

```text
Col(children: Node[], gap?: number, align?: "start" | "center" | "end" | "stretch")
```

이 항목의 예제는 Col 컴포넌트만 사용한다. 문자열을 각각 Col로 감싸 실제 요소 사이의 간격·정렬 차이를 보여준다.


### 예제 1. 기본 세로 흐름

```openui-lang
root = Col([Col(["첫 번째 항목"]), Col(["두 번째 항목"]), Col(["세 번째 항목"])])
```


### 예제 2. 간격 4 = 16px

```openui-lang
root = Col([Col(["첫 번째 항목"]), Col(["두 번째 항목"]), Col(["세 번째 항목"])], 4)
```


### 예제 3. 중첩과 정렬

```openui-lang
root = Col([Col([Col(["안쪽 A"]), Col(["안쪽 B"])], 2), Col([Col(["안쪽 C"]), Col(["안쪽 D"])], 4)], 6, "center")
```


## Row

자식 요소를 가로로 배치하고 간격·정렬·줄바꿈을 지정한다.


**호출 계약**

```text
Row(children: Node[], gap?: number, align?: "start" | "center" | "end" | "stretch", justify?: "start" | "center" | "end" | "between", wrap?: boolean)
```

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.


### 예제 1. 기본 가로 배치

```openui-lang
root = Col([Row([Text("왼쪽"), Text("가운데"), Text("오른쪽")], 4)])
```


### 예제 2. 양끝 정렬

```openui-lang
root = Col([Row([Text("시작"), Text("끝")], 2, "center", "between", true)])
```


## Box

방향·여백·배경·테두리·크기를 지정하는 범용 컨테이너다.


**호출 계약**

```text
Box(children?: Node[], direction?: "row" | "col", gap?: number, padding?: number, background?: Color, radius?: Radius, border?: boolean, width?: Length, height?: Length, flex?: number, align?: "start" | "center" | "end" | "stretch", justify?: "start" | "center" | "end" | "between", wrap?: boolean)
```

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.


### 예제 1. 배경·테두리

```openui-lang
root = Col([Box([Text("배경과 여백")], "col", 2, 4, "surface", "lg", true)])
```


### 예제 2. 가로 컨테이너

```openui-lang
root = Col([Box([Text("가로 A"), Text("가로 B")], "row", 4, 6, "info", "xl")])
```


## Grid

자식 요소를 같은 너비의 열에 배치한다. 최소 자식 너비로 반응형 열 수를 조절한다.


**호출 계약**

```text
Grid(children: Node[], columns?: number, minChildWidth?: number, gap?: number)
```

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.


### 예제 1. 2열 그리드

```openui-lang
root = Col([Grid([Card(["A"]), Card(["B"]), Card(["C"]), Card(["D"])], 2, 120, 4)])
```


### 예제 2. 반응형 최소 너비

```openui-lang
root = Col([Grid([Card(["A"]), Card(["B"]), Card(["C"])], 3, 160, 2)])
```


## Card

관련 콘텐츠를 테두리 또는 부드러운 배경의 패널로 묶는다.


**호출 계약**

```text
Card(children: Node[], variant?: "outline" | "soft", padding?: number, gap?: number)
```

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.


### 예제 1. 테두리 카드

```openui-lang

```


### 예제 2. 배경과 내부 간격

```openui-lang
root = Col([Card([Text("부드러운 배경"), Text("여백 6")], "soft", 6, 3)])
```


## Carousel

카드나 콘텐츠를 가로로 스크롤하고 항목 단위로 이동한다.


**호출 계약**


대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.

## SvgText

SVG 좌표에 정렬·크기·색상을 지정한 글자를 표시한다.


**호출 계약**

```text
SvgText(text: string, x: number, y: number, size?: number, fill?: Color, anchor?: "start" | "middle" | "end", weight?: "normal" | "medium" | "semibold")
```

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다. SVG 도형은 Svg 부모 안에서 렌더링합니다.


### 예제 1. 기본 사용 1

```openui-lang
root = Col([Svg([SvgText("Hello SVG", 80, 55, 20, "ink", "middle")], "0 0 160 100", 320, 200)])
```


### 예제 2. 기본 사용 2

```openui-lang
root = Col([Svg([SvgText("가운데 정렬", 80, 55, 16, "info", "middle", "semibold")], "0 0 160 100", 320, 200)])
```


## HtmlView

샌드박스 iframe 안에서 HTML과 인라인 JavaScript를 실행한다.


**호출 계약**

```text
HtmlView(html: string, height?: number, title?: string)
```

대상 항목을 중심으로 구성하며, 결과를 표시하거나 상태를 확인하기 위한 보조 컴포넌트를 함께 사용한다.


### 예제 1. 기본 사용 1

```openui-lang
root = Col([HtmlView("<h2>샌드박스 HTML</h2><p>독립된 HTML 콘텐츠입니다.</p>", 160, "HTML 예시")])
```


### 예제 2. 기본 사용 2

```openui-lang
root = Col([HtmlView("<button onclick=\"this.textContent=Number(this.textContent)+1\">0</button>", 120, "HTML 카운터")])
```

## 확인할 사항

- 계약의 인자 순서와 타입을 확인한다. 숫자와 숫자 문자열은 같지 않다.
- 코드를 읽을 때 초기 상태, 이벤트 발생, 계산 결과, 화면 갱신을 순서대로 따라간다.
- 기대 결과와 다른 경우 해당 함수나 컴포넌트의 계약, 상태 연결, 호스트의 오류 처리를 확인한다.
- 예제는 학습용이다. 모든 호스트에서 자동 실행되거나 동일한 카탈로그가 설치돼 있다는 의미는 아니다.
